# Full Stack Task Manager

A full-stack task management application built with a Vite frontend and Node.js/Express backend.

## Features

- User authentication
- Create, update, and delete tasks
- Manage task status
- Frontend built with Vite
- Backend built with Express

## Tech Stack

- Frontend: Vite, JavaScript, CSS
- Backend: Node.js, Express
- Database: MongoDB

## Project Structure

- `client/` - Frontend application
- `server/` - Backend application

## Installation

### Clone the repository
```bash
git clone https://github.com/pandugoud/fullstack-task-manager.git
cd fullstack-task-manager
```

### Install frontend dependencies
```bash
cd client
npm install
```

### Install backend dependencies
```bash
cd ../server
npm install
```

## Run the project

### Start backend
```bash
cd server
npm start
```

### Start frontend
```bash
cd client
npm run dev
```
